08-02
购物综合任务

你能够从商品页面提取规格和价格，向店员询价，说明退换货原因，并写下清晰的售后请求。

状态：已完成（审查与复审通过） 所属册：Book8 难度：应用 内容类型：真实场景综合任务

1. 学习目标

你能够从商品页面提取规格和价格，向店员询价，说明退换货原因，并写下清晰的售后请求。

2. 写作目的与读者

  • 口头对象：店员或客服。
  • 书面目的：请求更换尺寸不合适的商品；读者是售后人员。
  • 语体：口语礼貌直接；售后消息提供订单事实，不带责备语气。

3. 场景输入

听力稿

Customer: I’m looking for a waterproof backpack for a weekend trip. Clerk: This 25-liter model is on sale for $48. It has a padded laptop sleeve and a two-year warranty. Customer: Is the laptop sleeve large enough for a 14-inch computer? Clerk: Yes, a 14-inch laptop fits, but a 16-inch one does not. Customer: Can I return it if the straps are uncomfortable? Clerk: Unused items can be returned within 30 days. Used items can be exchanged only if they have a defect.

阅读输入：商品页面

TrailPack 25 Capacity: 25 L | Weight: 1.1 kg | Laptop sleeve: up to 14 in Price: $48 sale price (regularly $60) Returns: unused within 30 days; defects covered by a two-year warranty.

4. 受控练习

练习 A：找信息

写出容量、折后价、电脑尺寸上限和未使用商品的退货期限。

参考答案：25 L；$48；14 英寸；30 天内。

练习 B：询价与条件

用 How much... 和 What if... 各写一个关于商品价格和退货的问句。

参考答案示例：How much is it on sale? / What if the straps are uncomfortable?

练习 C：事实排序

将售后消息按顺序排列：订单号、购买日期、问题、请求、联系方式。

参考答案：订单号 -> 购买日期 -> 问题 -> 请求 -> 联系方式。

5. 综合输出任务

  1. 听力：记录容量、价格、保修和退货条件。
  2. 口语：询问两种尺寸，比较价格，提出退换货假设并确认规则。
  3. 阅读：判断一个使用过且无缺陷的背包是否符合退货条件，并说明依据。
  4. 写作：写 80-100 词的客服消息，说明商品、订单日期、尺寸问题，请求更换并提供订单号。

评分标准

维度达标表现需要改进
信息正确提取规格和政策把退货和保修混为一谈
询问能提出具体问题并追问问句缺少对象或条件
语气礼貌、事实导向指责或要求含糊
写作请求、订单事实和联系信息完整售后人员无法执行
