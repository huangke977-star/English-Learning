1. 学习目标

完成本单元后，你能够围绕一个中心意思写出主题句、支持句和结尾句，并使用连接词保持段落连贯。

2. 写作目的、读者与结构

  • 目的：解释一个选择、经历或建议。
  • 读者：同事、老师或普通读者。
  • 推荐结构：主题句 -> 2-3 个具体支持点 -> 例子/结果 -> 结尾句。

3. 范文

Working from home can save time, but it requires a clear routine. I do not spend time commuting, so I can start work earlier. However, I need to set a fixed start time and take regular breaks. I also keep my phone in another room during focused work. For these reasons, working from home works best for me when I follow a simple schedule.

主题句提出中心；中间句提供原因、限制和例子；结尾句回到中心并给出条件。每个支持句都应回答“为什么”或“例如什么”。

4. 常见错误

问题改进原因
一个段落同时写工作、旅行和食物每段只保留一个中心主题不集中
It is good. 没有证据It saves commuting time, for example.支持句要具体
开头没有主题句先写一句中心判断读者不知道段落方向
结尾引入全新观点用总结或条件收束保持段落范围

5. 受控练习

练习 A：排序

将下列句子按主题句、支持句、例子、结尾句排序：

  1. For example, I can review vocabulary on the bus.
  2. Short daily practice is an effective way to learn.
  3. It is easier to continue when the task is small.
  4. Therefore, I practice for fifteen minutes every morning.

参考答案：2 -> 3 -> 1 -> 4。

练习 B：补充支持句

主题句：A written checklist helps me finish tasks. 写两个具体支持句。

参考答案示例：It shows me what to do first. It also helps me notice unfinished work.

6. 输出任务与评分标准

  • 写作任务：写一个 100-120 词的单段短文，主题为“一个有效的学习习惯”。
  • 修改任务：用颜色或符号标出主题句、支持句、例子和结尾句。
  • 达标标准：中心单一；至少两个具体支持点；结尾不引入无关信息。
维度达标表现需要改进
组织主题句、支持句、结尾清楚句子像清单，中心不明
连贯使用时间、因果或转折连接句子跳跃
细节有例子或具体事实只用空泛形容词
