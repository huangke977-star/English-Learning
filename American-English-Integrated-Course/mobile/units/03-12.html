1. 学习目标

完成本单元后，你能够在需要突出动作对象时使用被动语态，并识别自然口语中不影响理解的省略现象，在口语和写作之间切换。

2. 核心规则

  • 被动语态的基本结构是 be + 过去分词：The form is signed. 时态由 be 表示：was sent、has been approved、will be delivered。
  • 不知道、无需强调或不想说明动作执行者时使用被动；需要强调执行者时用 by + 人/机构：The report was prepared by our team.
  • 及物动词才能构成常规被动。没有宾语的 arrive、happen 等不能直接改成被动。
  • 口语中常省略重复主语、宾语或上下文已知成分：Want some coffee? = Do you want some coffee?；省略只适用于语境清楚的非正式交流。
  • 正式写作中保留完整主语和谓语；不要把口语省略直接搬进报告、申请或正式邮件。

3. 例句

功能英文IPA中文
一般现在时被动The room is cleaned every day./ðə rum ɪz klind ˈɛvri deɪ/房间每天打扫。
一般过去时被动The package was delivered yesterday./ðə ˈpækɪdʒ wəz dɪˈlɪvɚd ˈjɛstɚdeɪ/包裹昨天送达了。
说明执行者The design was created by Maya./ðə dɪˈzaɪn wəz kriˈeɪtɪd baɪ ˈmaɪə/设计由 Maya 完成。
现在完成时被动The request has been approved./ðə rɪˈkwɛst hæz bɪn əˈpruvd/请求已经获批。
将来被动The results will be posted tomorrow./ðə rɪˈzʌlts wɪl bi ˈpoʊstɪd təˈmɑroʊ/结果明天公布。
口语省略Want to join us?/wɑnt tə dʒɔɪn ʌs/想和我们一起吗？
口语省略Sounds good./saʊndz ɡʊd/听起来不错。
口语省略Need a hand?/nid ə hænd/需要帮忙吗？

been 在自然口语中常弱读为 /bɪn/，will 也可能弱读；这属于发音变化，不代表书面拼写可以省略。Want to...、Sounds good 等省略句适合熟悉的口语场景，正式文本应写完整句。

4. 常见错误

错误修正原因
The report wrote yesterday.The report was written yesterday.被动需要 be + 过去分词
The accident was happened at noon.The accident happened at noon.happen 不及物，不能用常规被动
The email is send by Tom.The email is sent by Tom.send 的过去分词是 sent
在正式报告中写 Need more data.We need more data.正式书面语应保留主语

5. 受控练习

练习 A：改为被动

  1. The team completed the test.
  2. Someone has locked the door.

参考答案：1 The test was completed by the team. 2 The door has been locked.

练习 B：判断语体

判断 Want some tea? 和 Would you like some tea? 哪句更适合正式接待，并说明原因。

参考答案：Would you like some tea? 更适合正式接待；Want some tea? 是熟人之间的口语省略。

6. 综合输出任务

选择“包裹配送、维修工单或活动安排”之一，先写一段 100 词左右的正式通知（至少 4 个被动句），再把其中 3 句改写成对同事说的自然口语。标注哪些成分被省略，以及省略后为什么仍然清楚。
