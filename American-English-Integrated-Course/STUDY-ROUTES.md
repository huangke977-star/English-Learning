# 跨模块学习路线

本文件说明学习者如何在不同册之间交叉学习。它是学习建议，不替代各册的正文内容。

## 一、导航原则

1. 以 `BookX §XX-YY` 作为稳定定位。
2. 每学完一个小段，按照“复习 -> 听辨或阅读输入 -> 口语或写作输出”的顺序转入相关模块。
3. 不要求每天同时学习所有模块；采用一个主模块配一到两个辅助模块。
4. 跨模块建议必须写在单元正文结尾，不能只放在本文件中。
5. PDF 页码只作为带版本号的辅助信息，排版变更后必须复核。

Book3 §03-06 至 §03-12 完成后，先用 Book5 §05-04 澄清与确认、Book6 §06-05 日常邮件和 Book7 §07-02 句子连接各做一次转移练习，再进入 Book4 §04-01。学习 Book4 的每个主题词汇时，按“词汇 -> 口语 -> 阅读 -> 写作”的路线继续交叉学习。

Book1 §01-01 至 §01-10 完成后，学习者进入 Book2 §02-01；发音复习继续通过 Book2 的语流例句和 Book5 的短句跟读保持。

Book2 §02-01 至 §02-12 完成后，学习者进入 Book3 §03-01；弱读、连读和重音继续通过 Book3 例句以及后续口语、阅读任务复现。

## 四、Phase 3：词汇、口语、阅读交叉路线

每完成一个 Book4 主题词汇单元：

```text
Book4 主题词汇 -> Book5 同主题口语句型 -> Book6 同主题阅读 -> Book7 写 5-8 句短文
```

例如完成“工作、任务和会议”后，依次进入：

1. Book5 §05-09：工作交流和会议
2. Book6 §06-06：工作信息和简报
3. Book7 §07-09：工作汇报和问题说明
4. Book8 §08-05：工作沟通综合任务

Book4 §04-01 至 §04-12 完成后，先从每章输出任务中挑选 3 个主题复述，再进入 Book5 §05-01 至 §05-03。学习 Book5 时继续回到 Book4 对应主题，要求每次口语输出至少复用 5 个词语或搭配；随后用 Book6 的同主题材料和 Book7 的短写作巩固。

Book5 §05-01 至 §05-12 完成后，进入 Book6 §06-01 至 §06-03，先把口语句型作为阅读中的可识别语块，而不是逐词翻译。每学完一篇 Book6 材料，选择 2-3 个句型完成口头复述，再用 Book7 对应章节写出一条消息或一个短段落。

Book6 §06-01 至 §06-12 完成后，进入 Book7 §07-01。写作先模仿 Book6 的句子、连接方式和语体：从通知、聊天和邮件的短输出开始，再迁移到叙事、说明和观点段落。每次写作前先标出一篇相关阅读材料的目的、读者、结构和 3 个可复用语块。

Book7 §07-01 至 §07-12 完成后，进入 Book8 §08-01。先从 Book6 的通知、邮件和说明材料中提取事实，再用 Book7 的邮件/短文结构写下确认信息；最后用 Book5 的口语句型完成同一场景的听说读写任务。

Book8 按以下顺序完成综合闭环：

1. §08-01 餐厅 -> §08-02 购物：先练请求、核对和短消息，再迁移到商品政策和售后请求。
2. §08-03 旅行与住宿 -> §08-04 看病与求助：练时间、条件和安全信息的提取与确认。
3. §08-05 工作沟通 -> §08-06 电话与视频会议：把会议行动表迁移到远程澄清和纪要。
4. §08-07 社交活动 -> §08-08 租房、维修和公共服务：分别练友好语气与事实型工单。
5. §08-09 综合问题解决 -> §08-10 场景综合测评：从多份输入做选择，再用测评检验听说读写迁移。

每个 Book8 单元都采用同一节奏：先盲听或速读输入，第二遍标记事实；再做受控练习；接着完成口头角色扮演；最后写下可执行的消息、邮件或工单。完成 §08-10 后，把测评中记录的三类错误带入 Book9 对应复习章。

Book9 的复习顺序为：§09-01 发音和 IPA -> §09-02 语流 -> §09-03 语法句型 -> §09-04 词汇搭配 -> §09-05 听力 -> §09-06 口语 -> §09-07 阅读 -> §09-08 写作 -> §09-09 综合测试 -> §09-10 错误档案。每章先回看对应册，再做测试；未达标时只回补最低分能力，不必整册重学。

完成 §09-09 后，用 §09-10 建立 3/7/14 天复习循环。Book2 的自然速度、慢速和对比 MP3 均可用于训练；完整课程 MP3、PDF 排版和页码索引现已生成，遇到源文件更新时再按同样流程复核音频、链接和版本号。

## 五、Phase 4-5：写作与综合任务

写作不应等到最后才开始。基础写作从 Phase 2 以短句开始，Phase 3 进入消息和段落，Phase 4 才系统展开邮件和多段短文。

每完成一项 Book7 写作任务，至少回到一个相关的 Book6 阅读材料，模仿其结构或语气；完成 Book8 场景时，再把阅读、听力、口语和写作串成一项任务。

## 六、单元导航写法

每个单元结尾使用以下结构：

```markdown
## 学习导航

- 先复习：BookX §XX-YY
- 下一步：BookX §XX-YY
- 然后：BookX §XX-YY
- 输出任务：完成……
- 复习安排：当天、3 天后、7 天后
- PDF 参考页码：PDF vX.Y，第 N 页（模板占位；实际教材须替换为已核对的版本号和页码）
```

## 七、学习时长建议

### 每日 15 分钟

- 8 分钟主模块
- 4 分钟听辨或跟读
- 3 分钟复习和记录

### 每日 30 分钟

- 15 分钟主模块
- 8 分钟辅助模块
- 5 分钟口头或书面输出
- 2 分钟错误记录

### 每日 60 分钟

- 25 分钟主模块
- 15 分钟听力或阅读输入
- 15 分钟口语或写作输出
- 5 分钟复习和计划下一单元
