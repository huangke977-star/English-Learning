# 05-07 描述经历、问题和变化

> 状态：已完成（审查与复审通过）  
> 所属册：Book5  
> 难度：初级至中级  
> 内容类型：口语句型与交际策略

## 1. 学习目标

完成本单元后，你能够按时间顺序讲述经历，说明问题的影响和已采取的措施，并描述过去到现在的变化。

## 2. 核心句型

| 功能 | 句型与例句 | IPA | 自然形式/重音 | 中文与语体 |
| --- | --- | --- | --- | --- |
| 开始叙述 | Last month, I started a new project. | `/læst mʌnθ aɪ ˈstɑrtɪd ə nu ˈprɑdʒɛkt/` | 时间短语后停顿 | 上个月我开始了一个新项目。普通 |
| 背景 | At first, the process was confusing. | `/ət fɝst ðə ˈprɑsɛs wəz kənˈfjuzɪŋ/` | `At first` 轻读 | 起初这个流程很让人困惑。普通 |
| 转折 | Then we found a simpler way. | `/ðɛn wi faʊnd ə ˈsɪmplɚ weɪ/` | `Then` 引出下一步 | 后来我们找到了更简单的方法。普通 |
| 结果 | As a result, we saved time. | `/æz ə rɪˈzʌlt wi seɪvd taɪm/` | 正式连接词 | 因此我们节省了时间。普通 |
| 报告问题 | The main problem is that the app crashes. | `/ðə meɪn ˈprɑbləm ɪz ðæt ði æp ˈkræʃɪz/` | `main problem` 重读 | 主要问题是应用会崩溃。普通 |
| 影响 | This means we lose important data. | `/ðɪs minz wi luz ɪmˈpɔrtənt ˈdeɪtə/` | `means` 重读 | 这意味着我们会丢失重要数据。普通 |
| 已采取措施 | We've already contacted support. | `/wiv ɔlˈrɛdi ˈkɑntæktɪd səˈpɔrt/` | `already` 快速连接 | 我们已经联系了客服。普通 |
| 变化 | The situation has improved since then. | `/ðə ˌsɪtʃuˈeɪʃən hæz ɪmˈpruvd sɪns ðɛn/` | `since then` 重读 | 从那以后情况改善了。普通 |

经历叙述常用“时间 -> 背景 -> 问题/行动 -> 结果”的顺序。`I had a problem` 只介绍问题；说明影响时补上 `This meant...` 或 `As a result...`，听者更容易跟上。

## 3. 替换槽与叙述结构

```text
Last [week/month], I [started/visited/tried] [project/place].
At first, [problem/background].
Then we [action]. As a result, [outcome].
Since then, [change].
```

讲问题时使用事实和影响，避免只说 `It was bad`。时间不确定时可说 `recently`；明确变化时使用 `has/have + 过去分词`。

## 4. 常见错误

| 错误 | 修正 | 原因 |
| --- | --- | --- |
| `Last month I have started...` | `Last month I started...` | 明确过去时间用一般过去时 |
| `The problem make us late.` | `The problem made us late.` | 过去叙述使用过去式 |
| `Since then, it improved.` | `Since then, it has improved.` | 从过去持续到现在用现在完成时 |
| `We discussed about the issue.` | `We discussed the issue.` | `discuss` 后不加 `about` |

## 5. 受控练习

### 练习 A：排序

将句子按叙述顺序排列：`As a result, we changed the plan.`、`At first, the schedule was unclear.`、`Then we asked for help.`

参考答案：`At first...` -> `Then...` -> `As a result...`。

### 练习 B：时态选择

1. `Last year, I (joined / have joined) a class.`
2. `Since then, my confidence (improved / has improved).`

参考答案：1 `joined`；2 `has improved`。

## 6. 输出任务

- 口语：讲述一次解决问题的经历，时长 60-90 秒，包含背景、问题、措施、结果和变化。
- 写作：写 100-120 词的问题说明，明确影响、已采取措施和下一步请求。
- 完成标准：时间线清楚；至少使用一个过去时、一个现在完成时和两个结果连接词。
