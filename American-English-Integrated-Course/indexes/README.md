# Indexes

本目录维护可检索索引，后续逐步生成：

- 词汇索引
- 搭配和短语动词索引
- 语法索引
- 口语表达索引
- IPA 音素索引
- 场景索引：见 `08-scenario-index.md`
- 复习与测试索引：见 `09-test-index.md`
- PDF 页面索引：见 `page-index.md`；分册索引见 `../output/pdf/bookN-page-index.md`

新增、删除或重命名教材内容后，应同步更新相关索引。

页面索引由 `tools/build_pdfs.py` 自动生成。PDF 排版或源文件发生变化后，必须重新生成 PDF、渲染抽查并更新索引。
