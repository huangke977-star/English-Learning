# American English Integrated Course

《美式英语综合能力训练教材》是一套面向中文母语学习者的长期维护型英语学习项目。

## 项目目标

通过同一套循序渐进的材料，训练五项能力：

- 发音：读准常见美式英语音素和重音
- 听力：听辨自然语流并理解主要信息
- 口语：完成日常、工作和社交交流
- 阅读：理解从通知、邮件到一般文章的不同材料
- 写作：写出清晰、准确、符合语体的英文

项目路线是：

```text
发音基础 -> 语流听辨 -> 语法与词汇 -> 高频表达 -> 分级阅读 -> 写作输出 -> 真实任务
```

## 使用方式

每个单元都应完成以下闭环：

```text
学习目标 -> 输入材料 -> 规则或结构 -> 受控练习 -> 输出任务 -> 审查 -> 修改 -> 复审
```

学习者可以按路线顺序学习，也可以通过 `indexes/` 按词汇、语法、表达或音素查找内容。

教材采用“主模块 + 辅助模块”的交叉学习方式。每个单元结尾的“学习导航”会说明：当前内容学完后，应转到哪一册的哪一章哪一节、是否需要先复习，以及完成什么练习后再继续。完整的跨模块路线见 `STUDY-ROUTES.md`。

正文使用册、章、节编号作为稳定定位；PDF 页码只作为带版本号的参考页码。内容调整后，必须重新生成并检查页码索引。

## 材料完成门槛

“写完”不等于“完成”。每份学习材料必须经过独立审查，至少检查：

- IPA、拼写、语法、翻译和事实
- 学习目标、解释、练习、答案和评分标准是否齐全
- 表达是否真实，语体和难度是否合适
- 术语、符号、格式和前后章节是否一致
- 是否与已有材料重复或遗漏必要内容

审查记录使用 `templates/Material-Review-Record.md`。没有审查记录，单元不得标记为完成，也不得进入下一阶段。

## 内容约定

- 默认使用现代美式英语；存在地区或语体差异时明确标注
- 使用 IPA，不使用中文谐音代替发音说明
- 重要例句尽量同时提供标准形式、自然语流形式、中文翻译和发音说明
- 阅读材料逐步减少对逐句翻译的依赖
- 写作任务必须说明写作目的、读者、结构和自检方法
- 口语与书面语必须明确区分

## 维护方式

新增或修改内容时：

1. 复制 `templates/Unit-Template.md` 建立单元文件。
2. 按 `ROADMAP.md` 中的顺序填写内容。
3. 使用 `templates/Material-Review-Record.md` 完成审查和复审。
4. 更新对应索引和路线图状态。
5. 仅在审查通过后提交为已完成内容。
