# 00-05 跟读、复述与录音

> 状态：已完成（审查与复审通过）  
> 所属册：Book0  
> 难度：基础  
> 内容类型：口语方法

## 1. 学习目标

完成本单元后，你能够：

- 区分“看着文本朗读”“延迟跟读”和“脱稿复述”。
- 用录音检查发音、重音、停顿和表达完整度。
- 通过同一材料逐步减少对文本的依赖。

## 2. 四轮跟读法

示例句：

> I need to check my schedule.

1. **理解**：先读懂意思，标出需要表达的关键词。
2. **同步朗读**：看文本，与音频同时读，重点模仿节奏。
3. **延迟跟读**：音频说完一个意群后再跟读，不抢音频。
4. **脱稿复述**：合上文本，用自己的话复述主要信息。

跟读不是机械追赶速度。如果无法保持清楚发音，应降低速度或缩短材料。

## 3. 录音检查表

- [ ] 关键词是否突出？
- [ ] 是否把每个词读成同样重？
- [ ] 意群之间是否有自然停顿？
- [ ] 词尾辅音是否经常丢失？
- [ ] 是否为了模仿速度而牺牲清晰度？
- [ ] 脱稿复述是否保留了原句的主要意思？

## 4. 口语输出练习

将示例句中的词替换为自己的信息：

```text
I need to check my ______.
I need to call ______.
I need to finish ______.
```

录制三遍：第一遍看稿，第二遍延迟跟读，第三遍脱稿表达。

## 5. 验收标准

- 能连续说完 3-5 句，不因追求速度频繁停顿。
- 能指出自己录音中的一个发音问题和一个节奏问题。
- 能不看文本说出示例句的意思。
