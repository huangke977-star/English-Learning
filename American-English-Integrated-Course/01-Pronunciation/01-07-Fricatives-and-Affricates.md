# 01-07 摩擦音与塞擦音

> 状态：已完成（审查与复审通过）  
> 所属册：Book1  
> 难度：基础  
> 内容类型：发音

## 1. 学习目标

完成本单元后，你能够区分常见摩擦音和塞擦音，尤其是 `/θ-ð/`、`/f-v/`、`/s-z/`、`/ʃ-ʒ/`、`/tʃ-dʒ/`。

## 2. 发音方法

摩擦音让气流通过狭窄通道，产生持续摩擦；塞擦音先完全阻塞，再以摩擦方式释放。

| 对比 | 发音要点 | 例词 |
| --- | --- | --- |
| `/f-v/` | 下唇接近上齿；`/v/` 有声带振动 | `fan /fæn/` — `van /væn/` |
| `/θ-ð/` | 舌尖接近上下齿之间；`/ð/` 有振动 | `thin /θɪn/` — `this /ðɪs/` |
| `/s-z/` | 舌尖靠近齿龈；`/z/` 有振动 | `sip /sɪp/` — `zip /zɪp/` |
| `/ʃ-ʒ/` | 舌身靠近后齿龈；`/ʒ/` 有振动 | `mission /ˈmɪʃən/` — `vision /ˈvɪʒən/` |
| `/tʃ-dʒ/` | 阻塞后摩擦释放；`/dʒ/` 有振动 | `cheap /tʃip/` — `jeep /dʒip/` |
| `/h/` | 声门处气流摩擦，后面元音决定口腔形状 | `hat /hæt/` |

`/θ/` 和 `/ð/` 的舌尖不需要伸得很远，也不能直接用 `/s/` 或 `/z/` 替代。发音时保持轻微可见的舌尖位置，再让气流通过。

## 3. 例句

| 英文 | 美式 IPA | 重点 |
| --- | --- | --- |
| This is a very big change. | `/ðɪs ɪz ə ˈvɛri bɪɡ tʃeɪndʒ/` | `/ð/`、`/v/`、`/tʃ/`、`/dʒ/` |
| She shares the same shoes. | `/ʃi ʃɛrz ðə seɪm ʃuz/` | `/ʃ/`、`/ð/`、`/z/` |
| I think this is fine. | `/aɪ θɪŋk ðɪs ɪz faɪn/` | `/θ/` 与 `/ð/` |

## 4. 受控练习

### 练习 A：清浊配对

为以下清音找出对应浊音：`/f/`、`/θ/`、`/s/`、`/ʃ/`、`/tʃ/`。

参考答案：`/v/`、`/ð/`、`/z/`、`/ʒ/`、`/dʒ/`。

### 练习 B：辨别舌位

朗读 `thin, this, fan, van, sip, zip`，逐个说明舌尖或嘴唇的位置，再录音检查是否保持词尾辅音。

## 5. 输出任务

用以下词槽造三句真实句子，并录音：

```text
I think ______ is ______.
This is a ______ change.
She shares ______.
```

至少使用两个本单元目标音；不要为了堆音而写不自然的句子。
