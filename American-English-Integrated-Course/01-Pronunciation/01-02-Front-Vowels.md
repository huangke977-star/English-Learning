# 01-02 前元音

> 状态：已完成（审查与复审通过）  
> 所属册：Book1  
> 难度：基础  
> 内容类型：发音

## 1. 学习目标

完成本单元后，你能够区分 `/i/`、`/ɪ/`、`/ɛ/` 和 `/æ/`，并在词和短句中保持前元音的舌位、嘴型和重音。

## 2. 发音要点

| 音素 | 舌位与嘴型 | 例词 |
| --- | --- | --- |
| `/i/` | 舌位高、靠前，嘴角略展开，肌肉较紧 | `see /si/` |
| `/ɪ/` | 比 `/i/` 更放松，舌位略低 | `sit /sɪt/` |
| `/ɛ/` | 舌位中等靠前，嘴张开 | `bed /bɛd/` |
| `/æ/` | 舌位低靠前，嘴张开较大 | `bad /bæd/` |

美式英语通常不把 `/i/` 写成必须带长度符号的 `/iː/`。长短是实际发音结果的一部分，不能只靠符号判断。

## 3. 最小对立对

| 对比 | IPA | 中文提示 |
| --- | --- | --- |
| `sheep — ship` | `/ʃip — ʃɪp/` | `/i/` 更紧、更高；`/ɪ/` 更松 |
| `leave — live` | `/liv — lɪv/` | 词尾 `/v/` 不能丢 |
| `men — man` | `/mɛn — mæn/` | `/æ/` 嘴张得更大 |
| `bed — bad` | `/bɛd — bæd/` | 舌位高度不同 |

不要把四个音简单记成中文的“衣、短衣、诶、啊”。应通过听辨和录音确认舌位。

## 4. 例句

| 英文 | 美式 IPA | 重点 |
| --- | --- | --- |
| I need to sit here. | `/aɪ nid tə sɪt hɪr/` | `need` 的 `/i/` 与 `sit` 的 `/ɪ/` |
| Please leave the key. | `/pliz liv ðə ki/` | 两个 `/i/` 需要保持清楚 |
| The men left early. | `/ðə mɛn lɛft ˈɝli/` | `/ɛ/` 和词尾辅音 |
| That man has a map. | `/ðæt mæn hæz ə mæp/` | 多个 `/æ/` 连续出现 |

## 5. 受控练习

### 练习 A：听辨

请让他人或音频随机朗读下列词，写下你听到的词：`ship / sheep / men / man / live / leave`。第二遍再看 IPA 核对。

### 练习 B：分类

将词按目标元音分类：`sit, see, bed, bad, leave, live, men, man`。

参考答案：

- `/i/`：`see, leave`
- `/ɪ/`：`sit, live`
- `/ɛ/`：`bed, men`
- `/æ/`：`bad, man`

### 练习 C：替换

用 `need / sit / leave / live` 完成并朗读：

```text
I ______ here.
I ______ in this city.
Please ______ the key.
I ______ more time.
```

参考答案不唯一；每句必须语法完整，并能解释目标元音。

## 6. 输出任务

录音朗读四组最小对立对，再读四个例句。回听后分别记录：舌位问题、嘴型问题、词尾辅音问题各一个。
