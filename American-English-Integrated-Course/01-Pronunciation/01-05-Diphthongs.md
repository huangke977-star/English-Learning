# 01-05 双元音

> 状态：已完成（审查与复审通过）  
> 所属册：Book1  
> 难度：基础  
> 内容类型：发音

## 1. 学习目标

完成本单元后，你能够读出 `/eɪ/`、`/aɪ/`、`/ɔɪ/`、`/oʊ/` 和 `/aʊ/`，并感知双元音在一个音节内的舌位移动。

## 2. 发音要点

双元音不是两个独立音节。发音从第一个位置滑向第二个位置，音节核心保持连续。

| 音素 | 移动方向 | 例词 |
| --- | --- | --- |
| `/eɪ/` | 中前元音 -> 较高前部 | `day /deɪ/` |
| `/aɪ/` | 低央元音 -> 高前部 | `my /maɪ/` |
| `/ɔɪ/` | 后圆唇元音 -> 高前部 | `boy /bɔɪ/` |
| `/oʊ/` | 后部元音 -> 较高后部 | `go /ɡoʊ/` |
| `/aʊ/` | 低央元音 -> 高后部 | `now /naʊ/` |

`/oʊ/` 在不同说话者的起始位置可能略有差异，但仍应保持一个连续音节，而不是读成两个平行元音。

## 3. 例词与句子

| 英文 | 美式 IPA | 重点 |
| --- | --- | --- |
| day | `/deɪ/` | `/eɪ/` 结束位置较高 |
| time | `/taɪm/` | `/aɪ/` 的滑动 |
| boy | `/bɔɪ/` | `/ɔɪ/` 的圆唇起点 |
| go | `/ɡoʊ/` | `/oʊ/` 保持连续 |
| now | `/naʊ/` | `/aʊ/` 的嘴型变化 |
| I might go out tonight. | `/aɪ maɪt ɡoʊ aʊt təˈnaɪt/` | 多个双元音和弱读 `to` |

## 4. 受控练习

### 练习 A：听辨

区分以下词对：`late — light`、`boy — buy`、`go — cow`、`day — die`。先听后看 IPA，并说明每组差异发生在哪个起始或结束位置。

参考答案：

- `late /leɪt/` 与 `light /laɪt/`：起始位置不同。
- `boy /bɔɪ/` 与 `buy /baɪ/`：起始位置不同。
- `go /ɡoʊ/` 与 `cow /kaʊ/`：结束方向不同。
- `day /deɪ/` 与 `die /daɪ/`：起始位置不同。

### 练习 B：滑动练习

先夸张地读出双元音的起点和终点，再逐渐缩短夸张幅度，保持一个连续音节。练习：`say, my, boy, go, now`。

## 5. 输出任务

录音朗读五个双元音各 3 个词，再读例句 `I might go out tonight.`。回听时检查是否出现两个音节、是否在音节末尾提前停止滑动。
